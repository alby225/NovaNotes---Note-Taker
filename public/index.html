RESTful API Architecture & Endpoints

Express.js route specifications and MongoDB CRUD mapping

GET /api/notes

Retrieve all notes with support for full-text search, category filtering, priority filtering, sorting, and pagination.

Query Params: ?search=test&category=Work&priority=High&isPinned=true&sortBy=updated
POST /api/notes

Create a new note with Mongoose schema validation and automatic timestamps.

{ "title": "System Design", "content": "Architecture specs...", "category": "Work", "priority": "High" }
GET /api/notes/:id

Fetch a single note by its MongoDB 12-byte ObjectId with 404 CastError protection.

PUT /api/notes/:id

Update existing note properties using findByIdAndUpdate with validation.

DELETE /api/notes/:id

Permanently remove a note document from the MongoDB collection.

PATCH /api/notes/:id/pin

Toggle the pinned status flag of a note atomically.

GET /api/notes/stats/overview

Execute MongoDB aggregation pipelines to calculate total notes, pinned count, and category distributions.
